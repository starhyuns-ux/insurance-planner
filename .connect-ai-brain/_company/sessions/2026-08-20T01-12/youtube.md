# 📺 레오 — 구체적이고 실행 가능한 한국어 지시

**📺 레오:** 구체적이고 실행 가능한 한국어 지시 📍

**작업 제목:** 유튜브 채널 분석 및 데이터 수집 📊

**지시 내용:**

1. YOUTUBE_DATA_API_KEY를 설정하여 YouTube Data API와의 연결을 확인하세요. 🔑
2. 최근 3개월간의 유튜브 채널 데이터를 수집하고, `trend_sniper` 도구를 사용하여 패턴을 분석해 다음 영상 기획안(제목·썸네일·후크)을 도출합니다. 📊
3. 수집된 데이터를 로컬 LLM(Ollama/LM Studio)로 전송하여, 데이터의 일관성과 정확성을 확인하세요. 🔥
4. 분석 결과를 기반으로, 2개의 에이전트에게 다음과 같은 작업을 배정하세요.
	* `my_videos_check` 에이전트: 최근 영상이 잘 올라갔는지 한눈에 봅니다. 조회수 중간값을 기준선으로 삼아 떡상/부진 영상을 자동 분류하고, 다음에 뭘 할지 짧은 제안까지 만들어줍니다. 📊
	* `competitor_brief` 에이전트: 경쟁 채널들의 최근 떡상 영상을 모아서, 로컬 LLM에게 **지시문 형식**의 다음 액션 브리프를 받아옵니다 — "이거 해야합니다 / 저거 해야합니다 / 이건 절" 🔥

**에이전트 배정:**

* `my_videos_check` 에이전트: 1명
* `competitor_brief` 에이전트: 1명

**산출물:**

* `trend_sniper` 도구의 분석 결과
* `my_videos_check` 에이전트의 다음 액션 브리프
* `competitor_brief` 에이전트의 경쟁 채널 분석 결과

**시각화:**

* 1개의 차트를 그려, 유튜브 채널의 최근 3개월간의 데이터를 시각화하세요. 📊
